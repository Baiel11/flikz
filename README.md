# Flikz (Movie App)

**🎬 A sleek, responsive movie search application that brings the cinema experience to your fingertips.**

</div>

---

### 🌟 Features

- **Search thousands of movies** - Find any movie by title with real-time results
- **Interactive Movie Cards** - Posters, ratings, release dates, and languages
- **Loading spinner** - Smooth UX during data fetching
- **Fully responsive** - Works flawlessly on mobile, tablet, and desktop

---

### 📱 Responsive Design

Built with Tailwind CSS, the app adapts perfectly to all screen sizes. From large desktop monitors to small mobile devices, the layout gracefully adjusts, ensuring movies are always visible and accessible.

---

### 🚀 Tech Stack

- React 19 + Vite
- TMDB API for movie data
- Tailwind CSS for styling
- React-Use for debouncing
